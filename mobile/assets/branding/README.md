# Branding

Coloca aquí los logos de tu organización (por ejemplo `logo.png` y `logo_on_dark.png`)
y referencia su ruta en `config/app.json` con `APP_LOGO` / `APP_LOGO_ON_DARK`.

También puedes usar una URL `https://...` en lugar de un archivo local.
Si no se configura ningún logo, la app muestra un ícono con el nombre de la app (`APP_NAME`).

Los archivos de imagen de esta carpeta están ignorados por git para que cada despliegue use los suyos.
